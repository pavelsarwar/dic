# Demra Ideal College — Phase 1 UI review

## Scope
- Bangla-first, bilingual (Bangla/English) college website
- Responsive homepage, About, Academics, Admissions, Notices, Gallery, Contact, Resources
- Science, Business Studies, Humanities higher-secondary streams
- EIIN: 137604 (verified on Dhaka Education Board)
- Static HTML/CSS/JavaScript optimized for eventual cPanel deployment
- Phase 2 (not started): secure role-based content administration and database

## Editorial policy
Do not invent admission dates, results, fee details, principal's name or achievement counts. The college must confirm official branding, principal, current contact information, approved notices, campus photos and current admissions.

## Hosting security blocker
The existing domain has had an indexed unrelated casino post (June 2026). Investigate possible compromise and avoid importing untrusted WordPress content. Secure, scan and rotate credentials before cPanel deployment.

## Review checklist
- Confirm brand colors and official crest
- Confirm text in Bangla and English
- Approve homepage layout and site navigation
- Provide official campus/college photos
- Verify principal message, admission regulations and contact details

**Current status:** the working frontend preview is available separately as a downloadable ZIP for approval; GitHub production deployment has not started.
